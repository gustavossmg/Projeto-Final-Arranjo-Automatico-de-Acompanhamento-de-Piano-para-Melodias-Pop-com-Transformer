# Projeto Final - Arranjo Automático de Acompanhamento de Piano para Melodias Pop com Transformer

== EXECUÇÃO ==

O código do trabalho se encontra em um arquivo ".ipynb". Basta executá-lo usando o Jupyter Notebook, Visual Studio Code ou Google Colab.

== REPRODUÇÃO DOS RESULTADOS ==

O IPython Notebook irá gerar os arquivos ".mid" e ".wav" em uma pasta ".zip" de 15 músicas quando for executado, 5 de cada sistema. As três primeiras músicas geradas (uma de cada sistema) podem ser ouvidas na última célula do projeto.

== DEPENDÊNCIAS ==

As instalações e importações das bibliotecas necessárias já estão inclusas no IPython Notebook.
